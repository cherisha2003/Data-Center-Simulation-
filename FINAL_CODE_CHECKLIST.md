# Submission checks — CSC 8840 Option 2

1. Create a new virtual environment in the extracted directory. Do not submit the environment folder.
2. Install the packages listed in `requirements.txt`.
3. Run `python -m pytest -q` and confirm the tests pass.
4. Run `python -m streamlit run app.py`.
5. Open the calibration, live system view, scenario comparison, sensitivity, mechanism checks, scientific audit and historical cross-check tabs.
6. Export the results needed for the report, including the baseline, drought, and efficient-cooling scenarios.
7. Explain the measured/estimated/assumed distinction during the demo.
8. Submit the code with the report and slides, using the course-required names.

The 2023 benchmark fit is calibration, not out-of-sample validation. The resource buffer and grid allocation are illustrative. The approximate Energy Plan values are a plausibility cross-check with chart-reading uncertainty.
